Reproduces the reference pipeline: train_test_split(test_size=0.2, random_state=42) → StandardScaler fit on the training split only → KNeighborsClassifier(n_neighbors=3) with Euclidean distance on standardized features. Same six-row dataset, same split seed, same scaling math — computed here in JavaScript instead of Python.

Worth flagging: the reported test accuracy is 0%, and that's a real result, not a display bug. With only 6 rows, an 80/20 split holds out 2 for testing — here, both happen to be the shortest/lightest pair (both Class 0) — while training on the remaining 4. The model ends up predicting Class 1 for both, since the test points sit outside the range the training data covers. It's a natural consequence of evaluating on a dataset this small, and a good illustration of why train/test splits need far more than 6 rows to be meaningful.
